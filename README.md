# Funambule

Un funambule avance sur un fil tendu très haut au-dessus de la ville. Garde-le en équilibre contre le vent, le plus loin possible.

Maintiens ← ou → (ou clique sur la moitié gauche ou droite du jeu) pour pencher la perche. Le funambule penche de plus en plus s'il n'est pas rattrapé. Le vent forcit avec la distance ; les flèches blanches montrent d'où il souffle. Chaque poteau franchi est une étape.

Ses données (records, réglages) sont rangées dans le dossier du plugin, que NeoDex sauvegarde (synchro cloud comprise).

## Installer

Dans NeoDex : **NeoStore → À découvrir → Funambule → Installer**.

Développer un plugin : voir le [SDK NeoDex](https://github.com/NDesumeur/neodex-sdk).
